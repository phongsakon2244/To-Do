# Thai Todo App

Vite + React + Tailwind CSS + lucide-react. All data lives in React state (no localStorage).

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

```
src/
  App.jsx               # main component (state, filters, add form)
  components/TodoItem.jsx
  constants.js          # priorities, filters, animation delay
  index.css             # Tailwind + animations
```
